# Vetratoria — статья о вингфойле

Самостоятельный адаптивный статический проект, собранный по исходному DOCX-журналу в формате кинематографической веб-статьи. Тексты остаются индексируемым HTML-текстом, а фотографии подключаются отдельными оптимизированными WebP-файлами.

## Структура

```text
index.html                     Семантическая разметка и SEO-метаданные
assets/styles/main.css         Основной дизайн статьи
assets/styles/responsive.css   Планшетная и мобильная адаптация
assets/scripts/main.js         Неблокирующая загрузка фотографий
assets/images/*.webp           34 фотографии из исходного документа
```

На широких экранах статья использует фиксированное оглавление и индикатор чтения. На планшетах и телефонах оглавление превращается в горизонтальную навигацию, тексты идут одной колонкой, а изображения сохраняют естественные пропорции.

## Локальный запуск

```bash
npm run dev
```

Затем откройте `http://localhost:4173`.

Сборщик и зависимости не требуются: проект можно публиковать на GitHub Pages, Cloudflare Pages, Vercel или любом статическом хостинге.
